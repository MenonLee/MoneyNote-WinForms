개인 일정 및 과제 관리 프로그램 기획안

C# Windows Forms + SQLite + GitHub 협업 프로젝트

1. 프로젝트 개요

항목 내용
프로젝트명 개인 일정 및 과제 관리 프로그램
개발 목적 사용자가 개인 일정, 과제, 시험, 약속 등을 등록하고 목록 조회, 수정, 삭제, 검색, 통계 확인을 할 수 있는 Windows 데스크톱 프로그램을 개발한다.
개발 환경 C#, Windows Forms, .NET, SQLite, GitHub
협업 방식 GitHub feature 브랜치 기반 협업 및 Pull Request 병합 방식
저장 방식 SQLite 데이터베이스 파일(schedule.db)을 사용하여 일정 데이터를 저장한다.
본 프로젝트는 WinForms의 Form 단위로 화면을 분리하고, SQLite DB 기능은 별도의 DatabaseHelper 클래스로 분리하여 팀원별 역할 충돌을 줄이는 방식으로 진행한다.

2. 프로젝트 필요성

대학 생활에서는 과제, 시험, 팀 프로젝트, 개인 약속 등 관리해야 할 일정이 많다. 이를 수기로 관리하거나 메신저, 메모장 등에 흩어져 관리하면 마감일을 놓치거나 우선순위를 파악하기 어렵다. 따라서 본 프로그램은 사용자가 일정을 한 곳에 등록하고, 마감일과 중요도, 카테고리, 완료 여부를 관리할 수 있도록 하는 것을 목표로 한다.

6. 데이터베이스 설계

SQLite를 사용하며, 일정 데이터는 Tasks 테이블에 저장한다.

컬럼명 자료형 설명
Id INTEGER PRIMARY KEY AUTOINCREMENT 일정 고유 번호
Title TEXT NOT NULL 일정 제목
Description TEXT 일정 내용
DueDate TEXT NOT NULL 마감일
Category TEXT 과제, 시험, 약속, 팀플 등 카테고리
Priority TEXT 높음, 보통, 낮음 등 중요도
IsCompleted INTEGER 완료 여부. 0은 미완료, 1은 완료
CreatedAt TEXT 일정 등록일

7. GitHub 협업 계획

브랜치 담당자 작업 내용
main 준서 최종 안정 버전 관리
feature/main-ui 준서 메인 화면, 버튼 연결, Program.cs, README
feature/database 정영 SQLite DB 연결 및 DatabaseHelper 구현
feature/add-task 성인 일정 등록 화면 및 DB 저장 기능
feature/task-list 범준 일정 목록 화면 및 날짜별 조회 기능

main 브랜치에는 직접 작업하지 않고, 각자 담당 feature 브랜치에서 작업한 뒤 Pull Request를 통해 병합한다. WinForms Designer 충돌을 줄이기 위해 한 Form은 한 명만 수정한다.

10. 예상 완성 결과

프로그램을 실행하면 메인 화면이 나타나고, 사용자는 일정 등록, 일정 목록, 일정 관리, 검색, 통계 기능을 선택할 수 있다. 등록된 일정은 SQLite DB에 저장되며, 프로그램을 종료한 뒤 다시 실행해도 데이터가 유지된다. 목록 화면에서는 저장된 일정을 표 형태로 확인할 수 있고, 관리 화면에서는 수정, 삭제, 완료 처리가 가능하다. 검색 화면과 통계 화면을 통해 사용자는 자신의 일정 상태를 더 쉽게 파악할 수 있다.

11. 기대 효과

  • GitHub 브랜치와 Pull Request를 활용한 팀 협업 방식을 경험할 수 있다.
