윈도우즈프로그래밍 5팀 - 개인 일정, 과제 프로그램

잘 모르겠으면 언제든지 서로 디코에서 정보교환하면서 합시당

****각자 가장 먼저 해야할 것****
1. GitHub Desktop 설치, Git 사이트 들어가서 Git 설치 (콘솔창에서 명령어로 깃허브 올리기 위함)
2. GitHub Desktop에서 File → Clone repository
3. 팀 프로젝트 저장소 clone
4. Visual Studio에서 .sln 파일 열기
5. main 브랜치에서 Fetch origin / Pull origin
6. 자기 브랜치 만들기
7. 자기 담당 Form만 작업
8. Commit
9. Push
10. Pull Request 생성

!!! 각자 작업한 코드들 메인에 바로 올리지 말고 반드시!!! 브랜치에 먼저 올리고 Pull Requests 할 것

깃허브, 브랜치, git명령어 등 잘 모르겠으면 반드시 gpt같은거 참고해서 확실하게 숙지해주세요
